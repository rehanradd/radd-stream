## Deliberate scope notes (see final report for the full list)

- Works cache untouched (120 s / 32 entries stays; the report's 300 s /
  10k shape assumes id-only entries). nginx `proxy_cache` (60 s) and
  popular-query prewarm are gate-deploy/ops steps, not code here.
- Stopword guard adapted: no `ORDER BY rank` on the candidate path, so a
  stopword-only query is a bare posting-list read, never the 332 ms
  ranked case; single stopwords keep whole-word semantics via FTS5.
- Prefix-on-last-token is the one deliberate behaviour change vs the
  LIKE substring: `dead` finds Deadpool/Deadloch, not Undead (benchmark
  §4.2, better relevance). Diacritics fold (`amelie` → `Amélie`).
- The FTS5 pair is built by the migration, NOT at server start; the
  gate deploy must run it after the rev swap (service stopped), then
  `verify`. A rev-merge builds a fresh DB file, so the pair must be
  rebuilt on the new file — the search falls back to LIKE until then.
